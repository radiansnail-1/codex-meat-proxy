# Learnings

- Public skill variants retain portability substitutions; personal variants may contain private routing. Reconcile reusable changes rather than replacing whole directories.
- Symlink installation shares files with a checkout but does not publish to GitHub. Copy installation replaces destination skill directories.
- Local validation, a pushed PR, and a merged main branch are distinct outcomes. Report each precisely.
- For timing complaints, measure the visible trigger-to-outcome interval; trimming nearby setup can miss the actual delay.
- Retiming a motion demo must move picture and sound cues together and be verified in the delivered export.

- Event eligibility can change by objective and over time; live diagnostics and successful publication are stronger evidence than a saved draft.
- Transport success does not establish accepted, unique, qualifying or attributed events. Match clocks, event types and acceptance fields before interpreting a count mismatch.
