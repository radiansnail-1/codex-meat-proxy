# Investigation communication

The entrypoint governs investigation and stopping conditions.

A useful question identifies the missing fact or decision, why it matters, and a recommended choice when there is a tradeoff. Include project/build identity only when needed to disambiguate. Continue independent useful work while waiting. Do not ask again for existing authorization.

A useful result explains the symptom, evidenced root cause, behavior changed, verification actually performed, and remaining uncertainty. Status labels and a rigid report template are optional.

When blocked, state the missing evidence, access, or decision; summarize the distinct approaches already tried and the smallest next action that can resolve it. Do not equate uncertainty with an architectural defect or stop solely because a fixed number of attempts failed.
